# paulisStudio
es una página web informativa y de contextualización del estudio de belleza Paulis Studio. encontramos la info de redes sociales, un enlace a whatsapp con posibilidades de agendamiento por servicio, escogiendo el estilista la hora y el día de la reserva. Además, se incluyen los servicios disponibles y se muestra los espacios destinados de trabajo.
